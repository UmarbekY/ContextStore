
# ContextStore 🛒

A simple and interactive shopping cart application built with React. ContextStore allows users to browse products, add items to their cart, manage quantities, and track the total price.

## ✨ Features

- 🛍️ Display a list of products
- ➕ Add products to the shopping cart
- ➖ Increase or decrease product quantities
- 🗑️ Remove products from the cart
- 💰 Calculate the total price automatically
- 🔢 Track the total number of items
- 💾 Persist cart data using `localStorage`
- 🌐 Navigate between Home and Contact pages

## 🛠️ Technologies Used

- React
- JavaScript (ES6+)
- React Context API
- `useReducer` for state management
- `useEffect` for side effects
- `localStorage` for data persistence
- Vite
- CSS

## 🚀 Getting Started

### Prerequisites

Make sure you have Node.js and npm installed.

### Installation

1. Clone the repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Navigate to the project directory:

   ```bash
   cd your-project-folder
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.

## 📦 Production Build

To create an optimized production build, run:

```bash
npm run build
```

To preview the production build locally, run:

```bash
npm run preview
```
